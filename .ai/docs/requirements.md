# Expense Tracker API

Build a REST API for managing personal expenses.

## Initial functionality

Users can:

1. Create an expense.
2. List expenses.
3. Get a single expense.
4. Update an expense.
5. Delete an expense.

Each expense contains:

- id
- amount
- description
- category
- date

The API should be written in Go.

The project should have automated tests.

Do not implement authentication yet.
Do not implement frontend/mobile functionality yet.
